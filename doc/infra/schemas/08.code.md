## Pourquoi LLM uniquement

Les signaux utiles sont qualitatifs et ne peuvent pas être extraits par un algorithme déterministe :

- Cohérence de style et d'organisation (ex : interface définie dans un fichier dédié vs inline)
- Qualité et intention des tests (cas limites, ordre d'écriture)
- Lisibilité, nommage, structure

**SonarQube n'est pas applicable ici** : les extraits sont des fragments hors projet, sans contexte de build. Les métriques obtenues seraient peu fiables. Les données de qualité de code sont déjà couvertes par `sonar-measures.json` sur le projet complet.
