# Axis Field Detail

Champs bruts exposés dans la vue détail de chaque axe.
Chaque champ porte un label, une description, et une valeur typée.

null = donnée absente ou non collectée pour ce profil.

---

## HARNESS

### Groupe : Context Engineering

    claudeMd
      Label       : Fichier CLAUDE.md
      Description : Présence du fichier principal d'instructions projet fourni à l'IA à chaque session
      Valeur      : 0 (absent) | 1 (présent) | null

    docsContextCount
      Label       : Fichiers de contexte
      Description : Fichiers décrivant l'architecture ou le domaine métier, lus par l'IA
      Valeur      : entier ≥ 0 | null

    docsSpecsCount
      Label       : Spécifications
      Description : Fichiers de specs fonctionnelles rédigés avant le code pour guider l'IA
      Valeur      : entier ≥ 0 | null

    docsBrainstormCount
      Label       : Brainstorms
      Description : Sessions d'exploration de solutions documentées et accessibles à l'IA
      Valeur      : entier ≥ 0 | null

    docsPlansCount
      Label       : Plans
      Description : Plans d'implémentation étape par étape générés ou validés avec l'IA
      Valeur      : entier ≥ 0 | null

    memoryCount
      Label       : Fichiers mémoire
      Description : Fichiers de mémoire persistante — l'IA retient des infos entre sessions
      Valeur      : entier ≥ 0 | null

    tasksCount
      Label       : Fichiers de tâches
      Description : Listes de tâches structurées permettant à l'IA de reprendre le travail en cours
      Valeur      : entier ≥ 0 | null

### Groupe : Configuration IA

    agentsMd
      Label       : Fichier AGENTS.md
      Description : Présence du fichier de configuration des agents IA opérant sur ce repo
      Valeur      : 0 (absent) | 1 (présent) | null

    settingsJson
      Label       : Configuration settings.json
      Description : Présence du fichier de paramétrage de l'outil IA au niveau projet (ex : Claude Code)
      Valeur      : 0 (absent) | 1 (présent) | null

    agentsCount
      Label       : Agents configurés
      Description : Nombre de sous-agents spécialisés que l'IA principale peut déléguer
      Valeur      : entier ≥ 0 | null

    skillsCount
      Label       : Skills configurés
      Description : Nombre de commandes slash personnalisées déclarées pour ce projet
      Valeur      : entier ≥ 0 | null

    hooksCount
      Label       : Hooks configurés
      Description : Scripts qui s'exécutent automatiquement avant ou après une action de l'IA
      Valeur      : entier ≥ 0 | null

    rulesCount
      Label       : Rules configurées
      Description : Fichiers de règles de comportement injectés dans chaque session IA
      Valeur      : entier ≥ 0 | null

    aiCoauthoredRatio
      Label       : Commits co-authored IA
      Description : Part des commits signés conjointement avec l'IA sur la période analysée
      Valeur      : décimal 0.0–1.0 | null   (ex : 0.85 = 85 % des commits co-signés)

### Groupe : Boucles

    ciMedianRunsToGreen
      Label       : Médiane runs CI
      Description : Nombre de tentatives CI avant qu'un pipeline passe au vert — 1 = premier coup
      Valeur      : entier ≥ 1 | null

## INTERVENTION

    totalPrCount
      Label       : Nombre total de PRs
      Description : Nombre de pull requests analysées sur la période
      Valeur      : entier ≥ 0 | null

    medianCorrectionCommitsAfterOpen
      Label       : Commits de correction (médiane)
      Description : Commits ajoutés après ouverture de la PR pour corriger des erreurs — 0 = livraison propre
      Valeur      : entier ≥ 0 | null

    mergedWithoutHumanEditCount
      Label       : PRs sans retouche (nombre)
      Description : Nombre de PRs mergées sans aucune modification humaine après ouverture
      Valeur      : entier ≥ 0 | null

    mergedWithoutHumanEditRatio
      Label       : PRs sans retouche (ratio)
      Description : Part des PRs acceptées telles quelles — 1.0 = jamais retouchées par un humain
      Valeur      : décimal 0.0–1.0 | null

    medianReviewCommentsReceived
      Label       : Commentaires de review (médiane)
      Description : Nombre médian de retours reçus par PR — 0 = code accepté sans discussion
      Valeur      : entier ≥ 0 | null

    humanCommitRatio
      Label       : Ratio commits humains
      Description : Part des commits écrits directement par un humain sans l'IA — 0.0 = tout produit par l'IA
      Valeur      : décimal 0.0–1.0 | null

## SIZE

### Groupe : Distribution

    xs
      Label       : PRs XS (ratio)
      Description : Part des PRs de moins de 10 lignes — correctifs ponctuels ou ajustements triviaux
      Valeur      : décimal 0.0–1.0 | null   (la somme xs+s+m+l+xl = 1.0)

    s
      Label       : PRs S (ratio)
      Description : Part des PRs de 10 à 50 lignes — petites features bien délimitées
      Valeur      : décimal 0.0–1.0 | null

    m
      Label       : PRs M (ratio)
      Description : Part des PRs de 50 à 200 lignes — complexité standard
      Valeur      : décimal 0.0–1.0 | null

    l
      Label       : PRs L (ratio)
      Description : Part des PRs de 200 à 500 lignes — features multi-étapes
      Valeur      : décimal 0.0–1.0 | null

    xl
      Label       : PRs XL (ratio)
      Description : Part des PRs de plus de 500 lignes — features multi-modules ou refactorings larges
      Valeur      : décimal 0.0–1.0 | null

### Groupe : Métriques brutes

    medianFilesChanged
      Label       : Fichiers modifiés (médiane)
      Description : Nombre médian de fichiers touchés par PR — indique la surface de changement habituelle
      Valeur      : entier ≥ 0 | null

    medianLinesChanged
      Label       : Lignes modifiées (médiane)
      Description : Nombre médian de lignes changées par PR (ajouts + suppressions)
      Valeur      : entier ≥ 0 | null
