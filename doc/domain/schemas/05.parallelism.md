# ParallelismProfile

Axe Parallèle — combien de chantiers avancent en même temps, habituellement.

Un pic isolé ne compte pas.

```
ParallelismProfile
  ├── maxConcurrentBranches: number | null
  ├── medianConcurrentBranches: number | null
  └── hasWorktreeInclude: boolean | null
```

## Champs

| Champ | Ce que ça mesure |
|---|---|
| `maxConcurrentBranches` | Nombre maximum de branches ouvertes simultanément sur la période. Indique la capacité maximale de parallélisation atteinte. |
| `medianConcurrentBranches` | Nombre médian de branches ouvertes simultanément. Reflète l'habitude réelle, sans être faussé par un pic isolé. |
| `hasWorktreeInclude` | Présence d'un fichier `.worktreeinclude`. Indique que le dev utilise les worktrees Git pour travailler sur plusieurs branches en parallèle sans changer de dossier. |
