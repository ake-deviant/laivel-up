# InterventionProfile

Axe Intervention — quand et combien la personne reprend la main sur le travail de l'IA.

Monter de niveau = reprendre moins souvent pour atteindre la même qualité.

```
InterventionProfile
  ├── totalPrCount: number | null
  ├── medianCorrectionCommitsAfterOpen: number | null
  ├── mergedWithoutHumanEditCount: number | null
  ├── mergedWithoutHumanEditRatio: number | null
  ├── medianReviewCommentsReceived: number | null
  └── humanCommitRatio: number | null
```

## Champs

| Champ | Ce que ça mesure |
|---|---|
| `medianCorrectionCommitsAfterOpen` | Nombre médian de commits ajoutés après ouverture de la PR. Élevé = le dev a dû retoucher le travail de l'IA après coup. |
| `mergedWithoutHumanEditCount` | Ratio de PR fusionnées sans aucune modification humaine après ouverture (0–1). Élevé = l'IA a livré correctement du premier coup. |
| `medianReviewCommentsReceived` | Nombre médian de commentaires de review reçus par PR. Élevé = le code nécessitait beaucoup de retours avant d'être accepté. |
| `humanCommitRatio` | Ratio de commits non co-signés par une IA (0–1). 0 = le dev n'a jamais commité seul, tout est produit par l'IA. Signal clé pour le niveau Gold. |
