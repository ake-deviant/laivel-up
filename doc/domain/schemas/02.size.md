# SizeProfile

Axe Taille — taille habituelle des features livrées avec l'IA.

```
SizeProfile
  ├── distribution: SizeDistribution | null
  │     ├── xs: number | null
  │     ├── s: number | null
  │     ├── m: number | null
  │     ├── l: number | null
  │     └── xl: number | null
  ├── medianFilesChanged: number | null
  └── medianLinesChanged: number | null
```

## Champs

| Champ | Ce que ça mesure |
|---|---|
| `distribution.xs` | Ratio de PR < 10 lignes. Trivial, correctif ponctuel. |
| `distribution.s` | Ratio de PR 10–50 lignes. Feature simple. |
| `distribution.m` | Ratio de PR 50–200 lignes. Complexité standard. |
| `distribution.l` | Ratio de PR 200–500 lignes. Feature multi-étapes. |
| `distribution.xl` | Ratio de PR > 500 lignes. Feature multi-modules. |
| `medianFilesChanged` | Nombre médian de fichiers touchés par PR. Indique la surface de changement habituelle. |
| `medianLinesChanged` | Nombre médian de lignes modifiées par PR (ajouts + suppressions). Volume de changement livré. |

### Depuis `pull-requests` (fallback si git-activity absent)

| Champ domaine | Champ source | Calcul |
|---|---|---|
| `distribution.*` | `[].changed_files` | classification xs/s/m/l/xl par seuils, puis ratio |
| `medianFilesChanged` | `[].changed_files` | médiane sur toutes les PR |
| `medianLinesChanged` | `[].additions` + `[].deletions` | médiane de (additions + deletions) par PR |
