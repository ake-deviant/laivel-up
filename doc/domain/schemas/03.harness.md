# HarnessProfile

Axe Harness — ce que la personne a mis en place autour du modèle.

```
HarnessProfile
  ├── contextEngineering: ContextEngineeringProfile | null
  │     ├── hasClaude: boolean | null
  │     ├── hasAgentsMd: boolean | null
  │     ├── hasDocsContext: boolean | null
  │     ├── hasDocsSpecs: boolean | null
  │     ├── hasDocsBrainstorm: boolean | null
  │     ├── hasDocsPlans: boolean | null
  │     ├── hasMemory: boolean | null
  │     └── hasTasks: boolean | null
  ├── behavior: BehaviorProfile | null
  │     ├── rulesCount: number | null
  │     ├── agentsCount: number | null
  │     ├── hooksCount: number | null
  │     ├── skillsCount: number | null
  │     ├── hasSettings: boolean | null
  │     └── aiCoauthoredRatio: number | null
  └── loops: LoopsProfile | null
        └── ciMedianRunsToGreen: number | null
```

## Champs

### contextEngineering — ce que l'IA sait (mémoire, architecture, conventions)

| Champ | Ce que ça mesure |
|---|---|
| `hasClaude` | Présence d'un `CLAUDE.md`. Instructions projet fournies à l'IA : contexte, conventions, règles de collaboration. |
| `hasAgentsMd` | Présence d'un `AGENTS.md`. Instructions dédiées aux agents IA opérant sur le projet. |
| `hasDocsContext` | Présence de `docs/context/`. Documentation de contexte projet accessible à l'IA. |
| `hasDocsSpecs` | Présence de `docs/specs/`. Spécifications techniques accessibles à l'IA. |
| `hasDocsBrainstorm` | Présence de `docs/brainstorm/`. Réflexions et explorations partagées avec l'IA. |
| `hasDocsPlans` | Présence de `docs/plans/`. Plans de développement accessibles à l'IA. |
| `hasMemory` | Présence de `aidd_docs/memory/`. Mémoire persistante : l'IA retient des infos entre les sessions. |
| `hasTasks` | Présence de `aidd_docs/tasks/`. Suivi de tâches structuré permettant à l'IA de reprendre le travail en cours. |

### behavior — comment l'IA agit (règles, agents, hooks, guardrails)

| Champ | Ce que ça mesure |
|---|---|
| `rulesCount` | Nombre de fichiers de règles. Encadrent le comportement de l'IA : ce qu'elle peut faire, comment répondre. |
| `agentsCount` | Nombre d'agents configurés. Sous-agents spécialisés que l'IA principale peut déléguer. |
| `hooksCount` | Nombre de hooks configurés. Automatisations déclenchées avant/après une action de l'IA. |
| `skillsCount` | Nombre de skills configurés. Raccourcis réutilisables pour déclencher des comportements précis. |
| `hasSettings` | Présence de `.claude/settings.json`. Configuration fine du comportement de l'IA au niveau projet. |
| `aiCoauthoredRatio` | Ratio de commits co-signés par une IA (0–1). Intensité réelle d'utilisation de l'IA dans la production de code. |

### loops — relance automatique jusqu'à ce qu'une commande passe

| Champ | Ce que ça mesure |
|---|---|
| `ciMedianRunsToGreen` | Nombre médian de runs CI avant que le build passe. 1 = le code passe du premier coup. Plus c'est élevé, plus il a fallu d'itérations pour atteindre un build vert. |
