# Profile

Informations contextuelles du développeur. Ne contribue pas directement au score.

```
DeveloperProfile
  ├── id: string                      [required]
  └── profile: Profile
        ├── role: string | null
        ├── experienceYears: number | null
        ├── stack: string[] | null
        ├── teamSize: number | null
        └── note: string | null
```

## Champs

| Champ | Ce que ça mesure |
|---|---|
| `id` | Identifiant unique du développeur. |
| `role` | Rôle déclaré (ex : frontend, fullstack, lead). Contexte interprétatif pour le score. |
| `experienceYears` | Années d'expérience déclarées. Contexte interprétatif, non scoré. |
| `stack` | Technologies utilisées. Permet de contextualiser les choix d'outillage IA. |
| `teamSize` | Taille de l'équipe. Contexte pour interpréter le niveau de parallelisme et d'intervention. |
| `note` | Note libre. Informations complémentaires non structurées sur le développeur. |
