# AiddLevel

Résultat de l'évaluation d'un développeur selon le référentiel AIDD.

Le niveau global est le niveau le plus bas atteint parmi les 4 axes — un niveau n'est atteint que si tous ses axes le sont.

```
AiddLevel
  ├── overallLevel: AiddLevelValue        [required]  → niveau global (minimum des 4 axes)
  ├── sizeLevel: AiddLevelValue         [required]  → niveau atteint sur l'axe Taille
  ├── harnessLevel: AiddLevelValue      [required]  → niveau atteint sur l'axe Harness
  ├── interventionLevel: AiddLevelValue [required]  → niveau atteint sur l'axe Intervention
  └── parallelismLevel: AiddLevelValue  [required]  → niveau atteint sur l'axe Parallèle
```

```ts
const AiddLevelValue = {
  white: 'white',
  red: 'red',
  blue: 'blue',
  green: 'green',
  copper: 'copper',
  silver: 'silver',
  gold: 'gold',
} as const

type AiddLevelValue = typeof AiddLevelValue[keyof typeof AiddLevelValue]
```

## Champs

| Champ | Ce que ça mesure |
|---|---|
| `overallLevel` | Niveau global du développeur. Égal au niveau le plus bas parmi les 4 axes. |
| `sizeLevel` | Niveau atteint sur l'axe Taille : quelle taille de feature le dev livre habituellement avec l'IA. |
| `harnessLevel` | Niveau atteint sur l'axe Harness : ce que le dev a mis en place autour du modèle (contexte, behavior, boucles). |
| `interventionLevel` | Niveau atteint sur l'axe Intervention : à quel point le dev reprend la main sur le travail de l'IA. |
| `parallelismLevel` | Niveau atteint sur l'axe Parallèle : combien de chantiers avancent en même temps habituellement. |

## Règle de calcul du niveau global

```
level = min(size, harness, intervention, parallelism)
```

Exemple : si un dev est Silver sur 3 axes mais Red sur l'axe Taille, son niveau global est Red.
